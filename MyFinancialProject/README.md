# MyFinancialProject

这是一个金融数据相关的本地项目集合，包含 MCP 服务、报告规范与个人组合数据。

## 项目一览

- [FinancialMCP/](FinancialMCP/)：MCP 财务数据服务（HTTP/stdio）
  - 详细说明：见 [FinancialMCP/README.md](FinancialMCP/README.md)
- [FinancialMCP/PlanA/](FinancialMCP/PlanA/)：财务报告 PDF 输出规范
  - 详细说明：见 [FinancialMCP/PlanA/README.md](FinancialMCP/PlanA/README.md)
- [MyPortfolio/](MyPortfolio/)：个人投资组合与标的目录

## 快速开始（FinancialMCP）

在 [FinancialMCP/README.md](FinancialMCP/README.md) 中有完整说明。常用入口：

- [FinancialMCP/start-http.bat](FinancialMCP/start-http.bat)：启动 HTTP MCP 服务
- [FinancialMCP/start-stdio.bat](FinancialMCP/start-stdio.bat)：启动 stdio MCP 服务

## 备注

- 项目以 Windows 为主，脚本与路径按当前目录结构配置。
