# PlanA 输出规范（版式）

## 1. 报告结构（PDF）

PDF 必须包含以下结构，顺序固定：

1) 封面（Cover）
- 标题：`{公司名称/代码} 财务数据`
- 子标题：`报告期：{period_label}`（例如：2025Q3、2024年报）
- 口径：`合并报表 | 单位：人民币`（如适用）
- 生成时间：东八区时间

2) 目录（可选）
- 当报告内容超过 3 个章节时建议生成

3) 主要指标（Main KPIs）
- 以“卡片 + 小表格”呈现
- 必含：营收、净利润、资产合计、负债合计、所有者权益合计、经营现金流、资产负债率

4) 三大报表（Tables）
- 利润表（Income）
- 资产负债表（Balance Sheet）
- 现金流量表（Cash Flow）

5) 每股指标 + 能力指标（如数据可得）
- 每股收益（基本/稀释）、每股净资产、每股经营现金流等
- 盈利能力：毛利率、净利率、ROE、ROA
- 偿债能力：资产负债率、流动比率、速动比率

6) 同比/环比摘要（YoY / QoQ Summary）
- 对关键指标（营收、净利润、总资产、总负债、经营现金流）给出同比
- 如是季度报告：优先季度同比（同季度去年）
- 如是年报：优先年度同比（同年度去年）

7) 页脚
- 数据来源：Tushare（或接口名称）
- 免责声明（可选）：仅供参考

---

## 2. 表格样式（与截图对齐）

### 2.1 列结构

- 第一列：`指标名称`
- 后续列：按时间从近到远排列，例如：
  - `2025年三季报`、`2024年年报`、`2023年年报`
- 每个时间列下方可标注单位（如：人民币）

### 2.2 分组（Section Header）

报告中的“利润表 / 资产负债表 / 现金流量表 / 每股指标 / 盈利能力 / 偿债能力”以分组标题分隔，分组标题独占整行。

### 2.3 数字格式

- 大额数值（金额类）：优先以“亿”为单位展示（示例：`1,613.88亿`）
- 百分比：保留 2 位小数（示例：`-26.61%`）
- 无数据：展示 `—`

### 2.4 负数

- 负数直接展示 `-` 前缀（示例：`-257.84亿`）

## 3. PDF 文件产物

生成 PDF 时必须同时落盘：

- `*.pdf`（最终交付）
- `*.html`（用于排查版式）
- `report.json`（包含输入参数、取数元数据、关键指标数值、同比计算结果）

文件命名规则：

`{report_id}_{market}_{ts_code}_{period}_{generated_at}.pdf`

- `generated_at` 使用 `YYYYMMDD_HHMMSS`
