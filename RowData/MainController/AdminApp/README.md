# AdminApp

Lightweight web control deck for RowData and MyFinancialProject modules.

## Run

1. Install dependencies:

   - Use your existing Python environment.
   - `pip install -r requirements.txt`

2. Start the server:

   - `uvicorn main:app --host 0.0.0.0 --port 8000`

3. Open in browser:

   - `http://localhost:8000`

## Configure actions

Edit `app_config.json` and hit "Reload Config" in the UI.
